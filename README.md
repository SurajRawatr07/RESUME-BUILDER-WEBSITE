# ⚡ Getting Started

## 1️⃣ Clone Repository

```bash
git clone https://github.com/SurajRawatr07/RESUME-BUILDER-WEBSITE.git
```

## 2️⃣ Go To Project Folder

```bash
cd RESUME-BUILDER-WEBSITE
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Run Development Server

```bash
npm run dev
```
