## ✨ Overview

**SmartResume** is a modern resume-building platform designed to help students, developers, and professionals create polished, ATS-friendly resumes quickly.

It combines a clean editing experience with **real-time preview, professional templates, theme support, and PDF export**.

---

## 🚀 Features

| Feature | Description |
|---|---|
| 📄 Resume Builder | Create and edit resumes through a structured interface |
| 🎨 Professional Templates | Multiple clean and ATS-friendly resume layouts |
| 👀 Live Preview | See resume changes instantly |
| 📥 PDF Export | Download the finished resume as a PDF |
| 🤖 ATS Friendly | Structured layouts designed with ATS readability in mind |
| 🌙 Dark / Light Mode | Switch between themes seamlessly |
| 📱 Responsive UI | Optimized for desktop, tablet, and mobile |
| 🔐 Authentication | Secure user authentication experience |
| 📊 Dashboard | Manage resumes through a professional dashboard |
| ✨ Smooth UI | Modern transitions and micro-interactions |
