# 🚀 SmartResume — AI Powered Resume Builder

A modern and professional Resume Builder Website designed to help users create beautiful, ATS-friendly resumes with a clean UI, live preview, PDF export, and responsive experience.

👉 https://surajresumebuilder.netlify.app/
